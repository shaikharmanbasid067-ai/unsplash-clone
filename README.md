Unsplash Clone

A responsive Unsplash Clone built using HTML5 and CSS3. This project recreates the clean and modern look of Unsplash with a simple navigation bar, image gallery, and responsive layout.

Features

Responsive design

Modern and clean UI

Image gallery layout

Navigation bar

Mobile-friendly design

Built with pure HTML and CSS

Technologies

HTML5

CSS3
